# 任务描述

告警处理详情弹层中出现了横向滚动，体验不好，貌似是原始 json 负载这个 dom 导致的

# 分析

在 `web/src/pages/history.tsx` 中找到 "原始 JSON 数据负载" 部分。
目前的 `<pre>` 标签使用了 `overflow-x-auto`，导致长 JSON 字符串无法换行，从而产生横向滚动条。

# 提议的解决方案

将 `overflow-x-auto` 替换为 `whitespace-pre-wrap break-all`，强制长文本换行，消除横向滚动。
