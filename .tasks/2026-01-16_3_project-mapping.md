# 分析

payload 中包含 UTC 时间戳。后端数据库存储的时间可能缺少时区信息，导致前端按本地时间解析，产生了时差。
另外，前端展示的项目名称通过 `alert.project` 直接获取，显示的是项目 ID。已有 `projectsApi` 可获取项目 ID 到显示名称的映射。

# 提议的解决方案

前端 `history.tsx` 中增加 `parseDate` 函数，强制将无时区后缀的时间字符串视为 UTC 时间解析。
同时，在加载告警列表时一并加载项目映射列表，并使用 helper 函数将项目 ID 转换为显示名称。
